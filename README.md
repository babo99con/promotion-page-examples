# Promotion Page Examples

세일 페이지에서 자주 사용하는 UI 기능을 작은 예제로 분리한 프로젝트입니다.

## 예제

- 다중 이미지 슬라이드: 여러 혜택을 한 영역에서 순환 노출
- 쿠폰팩: 버튼 한 번으로 여러 쿠폰을 일괄 발급
- 카운트다운 타이머: 종료까지 남은 시간 표시
- 출석 체크: 브라우저 저장소를 이용한 7일 참여 기록

각 예제는 외부 API 없이 동작합니다. 출석 기록은 학습 편의를 위해 `localStorage`에 저장하며, 실제 서비스에서는 회원과 참여 날짜를 서버에서 검증해야 합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 검증

```bash
npm test
```

## 참고

이 프로젝트는 기능의 원리를 보여주는 프론트엔드 예제입니다. 실제 쿠폰 발급과 출석 이벤트에는 로그인, 서버 저장소, 중복 참여 방지, 행사 기간 검증이 추가로 필요합니다.
